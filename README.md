# Hotel Reservation System

Website reservasi hotel sederhana menggunakan PHP Native dan MySQL.

## Fitur

### User

- Register
- Login
- Logout
- Melihat daftar kamar
- Detail kamar
- Reservasi kamar

### Admin

- Login
- Dashboard
- CRUD Kamar
- Kelola Reservasi
- Mengubah status reservasi

---

## Teknologi

- PHP Native
- MySQL
- HTML
- CSS
- JavaScript
- Laragon
